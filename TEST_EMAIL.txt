

SO STARTEN SIE DAS SYSTEM

1. DOCKER IMAGE HOLEN

   docker pull saadarroub/assessment-system:latest

2. CONTAINER STARTEN
   Starten Sie den Container mit folgendem Befehl:
   
   docker run -d --name assessment-system -p 8080:8080 -p 5173:5173 saadarroub/assessment-system:latest

   Erklärung der Parameter:
   • -p 8080:8080    = Backend API Port (für die REST-API)
   • -p 5173:5173    = Frontend Port (für die Web-Oberfläche)

3. ANWENDUNG ÖFFNEN
   Nach dem Start erreichen Sie:
   
   → Frontend: http://localhost:5173
   → Backend API: http://localhost:8080
